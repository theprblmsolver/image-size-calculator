# Image Size Calculator

A fast, simple, browser‑based tool for calculating image dimensions, aspect ratios, and platform‑specific output sizes.

This tool is designed for creators, designers, and digital sellers who need to quickly determine the correct image dimensions for:

- Etsy
- Shopify
- Amazon
- WooCommerce
- eBay
- Instagram Post
- Instagram Story
- Facebook
- Pinterest
- Twitter / X
- Redbubble
- Printful
- Merch by Amazon
- Society6

No installation. No ads. No tracking. Just a clean, instant calculator.

## 🚀 Features

- Instant dimension calculations  
- Aspect ratio preservation  
- Auto‑scaling  
- Pixel density adjustments  
- Platform presets (optional)  
- 100% client‑side (no data leaves your browser)

---

## 🧩 How It Works

1. Enter your source width/height  
2. Choose your target platform or custom size  
3. The calculator outputs:
   - Required width/height  
   - Scale factor  
   - Aspect ratio  
   - Pixel density  
   - Recommended export size
